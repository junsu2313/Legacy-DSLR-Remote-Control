# 적응형 필름 시뮬레이션 기본 컨셉

작성일: 2026-08-24  
상태: 기본 컨셉 고정  
적용 대상: S10 라이브뷰 및 촬영 결과 미리보기

## 1. 핵심 정의

이 프로젝트의 필름 시뮬레이션은 프레임 위에 고정된 색상 필터를 얹는 기능이 아니다.
원본 프레임을 구역별로 분석하고, 각 구역의 특성에 맞춰 사용자가 선택한 필름 룩을
적응형으로 적용하는 이미지 렌더링 시스템이다.

```text
원본 640급 프레임
  ↓
구역별 특성 추출
  ↓
사용자 필름 설정과 결합
  ↓
구역별 보정 파라미터 결정
  ↓
원본 픽셀에 보정 적용
  ↓
질감 및 약한 효과 추가
  ↓
라이브뷰 표시
```

## 2. 구역 분석값

초기 구현은 화면을 3×3 또는 4×4의 겹치는 구역으로 나누는 것을 기준으로 한다.
구역의 평균값으로 화면을 채우지 않고, 분석값을 보정 파라미터를 결정하는 입력으로만 사용한다.

- 평균·중간 밝기
- 하이라이트와 섀도 비율
- 평균 색상과 색상 분포
- 채도
- 국부 대비
- 디테일/에지 정도

## 3. 사용자 설정과의 결합

사용자가 선택한 필름 프리셋은 기본 스타일과 전역 강도를 제공한다.
구역 분석값은 해당 스타일의 적용 강도와 세부 파라미터를 장면에 맞게 조절한다.

예시:

- 밝은 구역: 하이라이트 롤오프를 강화
- 어두운 구역: 섀도우 보정 강도를 조절
- 고채도 구역: 색상 계조 효과를 강화
- 피부톤으로 판단되는 구역: 색상 변화량을 제한
- 디테일이 적은 구역: Clarity와 그레인을 완화

## 4. 필름 시뮬레이션 구성

필름 룩은 다음 요소의 조합으로 구성한다.

- 베이스 색상 프로파일 또는 LUT
- 톤 커브와 하이라이트·섀도 제어
- 색상별 보정 및 화이트밸런스 시프트
- 대비·채도·선명도 조절
- 그레인, 비네팅, 할레이션, 약한 블룸

LUT와 톤 커브는 원본 픽셀 값을 변환한다. 그레인·먼지·할레이션 같은 질감은
변환된 결과 위에 별도 텍스처로 추가할 수 있다.

## 5. 해상도 및 처리 원칙

- 기준 입력은 기존 640급 라이브뷰 프레임이다.
- 색상·톤 분석과 적응형 파라미터 결정은 원본 프레임 기준으로 한다.
- 원본에 없는 디테일을 AI 업스케일로 만들어내는 것은 기본 경로에 포함하지 않는다.
- 필름 보정 후 필요한 경우 GPU 기반 일반 업스케일을 적용한다.
- 촬영 결과의 고해상도 처리는 라이브뷰와 분리한다.
- Opal은 프레임 전달만 담당하고 필름 시뮬레이션은 S10에서 처리한다.

## 6. 반드시 지킬 품질 기준

- 원본 프레임의 장면 구조와 디테일을 유지한다.
- 구역 경계가 보이지 않도록 구역 간 파라미터를 부드럽게 보간한다.
- 하이라이트 클리핑을 과도하게 유발하지 않는다.
- 피부톤을 과도하게 변형하지 않는다.
- 적응형 대비가 장면을 부자연스럽게 망가뜨리지 않도록 최대 강도를 제한한다.
- 같은 프리셋이라도 장면에 따라 자연스럽게 반응하되 결과의 정체성은 유지한다.

## 7. 구현 논의의 다음 범위

다음 논의에서는 이 컨셉을 변경하지 않고 아래 구현 베이스를 결정한다.

3. 분석값과 사용자 설정을 결합하는 파라미터 모델
4. LUT 포맷과 프리셋 JSON 구조
5. 라이브뷰와 촬영 결과의 품질·성능 분리
