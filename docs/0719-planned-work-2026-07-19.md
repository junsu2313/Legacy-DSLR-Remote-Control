# 0719 예정 과업

작성일: 2026-07-19  
버전: 1.0 Alpha  
상태: 오팔 실기 검증 완료 프로토타입 / 제품 릴리스 아님

이 문서는 0719 기준으로 확정한 다음 개발 순서와 범위를 기록한다.
이번 작업 범위는 세션 유지·복구와 라이브뷰 유지형 AF·셔터까지로 제한한다.
두 항목은 오팔 실기 검증까지 완료했지만, 장기 실사용 검증 전까지 프로토타입으로 고정한다.
제품 릴리스와 신뢰성 보증은 별도 실사용 검증 이후에만 재논의한다.

## 0. 선행 기반 작업 — 세션 유지·복구

- 세션 번호와 라이브 세션 정체성을 우선 유지한다.
- 브리지·WebSocket·워커·PTP 상태를 개별적으로 복구한다.
- 락·큐·캐시·임시 플래그를 정리한 뒤 같은 세션에서 재개한다.
- 단일 명령 실패나 일시적 프레임 지연만으로 세션을 재생성하지 않는다.
- PTP 세션 손실, USB 재연결, 복구 한도 초과 때만 세션 재생성을 허용한다.

## 1. 라이브뷰 유지형 AF·셔터

- 라이브뷰를 끄지 않고 AF를 실행한다.
- AF 버튼은 AF만 실행하며 셔터를 자동 실행하지 않는다.
- SHOT은 별도 사용자 입력일 때만 실행한다.
- 실제 카메라 PTP 명령은 공용 큐에서 직렬화한다.
- AF 성공·AF 불가·Device Busy·세션 미준비를 구분한다.

## 공통 완료 조건

- 카메라 없는 mock/fault 테스트 통과
- 세션·프로세스·PTP 장애 후 복구 확인
- 장시간 반복 테스트에서 중복 워커와 stale 세션 없음
- 실제 카메라 반복 검증
